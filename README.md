# 🏎️ PolyRacers API

🇫🇷 **PolyRacers API** est le backend (API REST) du jeu de course PolyRacers. Il gère l'authentification des joueurs, les sauvegardes du mode carrière et les données des courses.

🇬🇧 **PolyRacers API** is the backend (REST API) for the PolyRacers racing game. It handles player authentication, career mode saves, and racing data.

---

### ⚙️ Stack
Node.js • Express • MySQL

### 🚀 Quick Start
```bash
# Install dependencies
npm install

# Start the server (requires a .env file with DB & JWT credentials)
npm run dev
